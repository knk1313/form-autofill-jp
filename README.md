# Form Autofill JP

日本語と英語のWebフォームを見分けて、名前・フリガナ・住所・電話番号・生年月日などを入れるChrome拡張機能です。Chromeの標準の自動入力が苦手な、日本のフォームに特有の欄にも対応します。

## できること

| 欄 | 日本語のフォーム | 英語のフォーム |
| --- | --- | --- |
| 名前 | 姓・名に分かれた欄、1つの欄（`山田　太郎`） | First name・Last name、Full name（`Taro Yamada`） |
| 読み | カタカナ・ひらがな・半角カナを欄に合わせて変える | — |
| 電話番号 | 3つに分かれた欄、「ハイフンなし」の欄 | そのまま |
| 郵便番号 | 2つに分かれた欄（`100`・`0001`）、7桁の欄 | そのまま |
| 住所 | 都道府県の選択、市区町村・番地・建物、「住所1〜3」、1つの欄 | Address line 1・2、City、State（都道府県から自動）、Country |
| 生年月日 | 元号（昭和・平成・令和）と年・月・日の選択、`1990/01/23` など | 月・日・年の選択、`MM/DD/YYYY` など、例の形に合わせる |
| 性別・勤務先 | ラジオボタン・選択・入力欄 | 同じ |

- 欄のラベル・プレースホルダー・`name`属性・表の見出し・`autocomplete`属性から欄の種類を見分けます
- 日本語の欄か英語の欄かは、ラベルの文字とページの言語で決めます。「名（ローマ字）」のような欄には英字を入れます
- 入力済みの欄は上書きしません（ポップアップで上書きにも切り替えられます）
- パスワード・検索・件名・ユーザー名・お問い合わせ内容などの欄には入れません
- 入れた欄は2.5秒だけ緑の枠で囲みます
- 郵便番号を先に入れ、住所の自動入力（ajaxzip3など）が終わってから残りを入れます

## 入れ方

Chromeウェブストアには出していないため、このフォルダーを読み込みます。

1. Chromeで`chrome://extensions`を開く
2. 右上の「デベロッパー モード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」を押し、このフォルダーを選ぶ
4. 開いたプロフィールの画面に、自分の情報を入れて保存する

## 使い方

フォームのあるページで、ツールバーのアイコンを押して「このページに入力」を押します。`Alt+Shift+F`でも入力できます（入れた数がアイコンに出ます）。

**送る前に、入った中身を必ず確かめてください。** 欄の見分けは推測なので、違う欄に入ることがあります。

## プライバシー

- プロフィールは`chrome.storage.local`（このパソコンのChromeの中）にだけ保存します。同期もしません
- 外へ通信しません
- 権限は`activeTab`・`scripting`・`storage`だけです。アイコンかショートカットを押したタブにだけ、そのときだけスクリプトを差し込みます

## ファイル

| ファイル | 役割 |
| --- | --- |
| `fill.js` | 欄の見分けと入力（ページに差し込む） |
| `background.js` | ポップアップとショートカットから呼ばれ、`fill.js`を差し込む |
| `popup.html`・`popup.js` | ポップアップ |
| `options.html`・`options.js` | プロフィールの画面 |
| `style.css` | ポップアップとプロフィールの画面の見た目 |
| `test/` | 見本のフォーム（`ja.html`・`en.html`）と、入るべき値との突き合わせ |
| `scripts/check.sh` | `manifest.json`の形式とJSの構文の検査 |
| `scripts/make-icons.mjs` | アイコンの書き出し |

## 確かめ方

```sh
bash scripts/check.sh                          # manifest.json と JS の構文
npm i --no-save jsdom@24 && node test/run.cjs  # 見本のフォームに入れて、入るべき値と突き合わせる
```

`test/ja.html`・`test/en.html`をChromeで開いて、実際に入力を試すこともできます（`file://`のページで試すときは、拡張機能の詳細で「ファイルの URL へのアクセスを許可する」をオンにします）。

## 注意

- `chrome://`のページやChromeウェブストアでは動きません
- 別のドメインから埋め込まれたフォーム（iframe）には入らないことがあります
- 複数のプロフィール（個人用・仕事用など）にはまだ対応していません
